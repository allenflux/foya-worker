# 原生 Qwen · 独立文案输入版

导入 `Qwen2.1_宣传图_独立文案输入.json` 可保留当前服务器已有主素材。换服务器或重新传素材时使用 `空素材模板.json`。两份均只用 ComfyUI 原生节点，无需安装新的自定义节点。

- ③「上图文案」：只粘贴真正需要上图的完整文字，默认留空。空白时不要运行；本版没有程序化的空文案拦截。
- ④「设计要求」：只描述人物/产品的使用方式、设计风格、构图、背景、配色及目标语言，不填上图文案。风格可以不写；按素材匹配。
- ②「输出尺寸」：宽高建议32的倍数。编码器resolution保持0，不改变既有尺寸设置。
- ⑥「一次生成数量」：amount填1、2、3或4，工具栏Batch Count保持1。

文案原样经过 `PrimitiveStringMultiline → StringConcatenate → TextEncodeQwenImage21.prompt`，不会被字符串处理程序改写、裁剪、翻译或补写。原来700多字的模板说明和<copy>标签已从模型输入中删除；现在只有简短设计要求、固定逐字约束和实际文案。输入框标题、节点使用说明不发给模型。

API调用时，完整文案写入 `20.inputs.value`；设计要求写入 `21.inputs.value`；素材为 `10.inputs.image`；数量为 `6.inputs.amount`。整个图只提交一次/prompt，不循环提交单张。

这个改动修复文案输入与模板说明混杂。Qwen仍负责逐字生成，中文尤其长正文仍可能错字；分开输入并不等于字库排版，不能保证零错字。若必须保证每个字准确，需要由调用方使用字体渲染后合成，或明确采用排字步骤。未收到实际文案，本次没有填造示例文案、没有重新生成图片，也未声称视觉验收通过。

原生接口来源：[文本输入](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_primitive.py)、[字符串拼接](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_string.py)。
