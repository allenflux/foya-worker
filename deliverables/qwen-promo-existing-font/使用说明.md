# 使用你已安装的节点排字

本版**不包含也不依赖 `ExactPromoTextPrepare`**，没有新增 Python 节点或 pip 依赖。

已在你当前节点库中确认有 Essentials 的 **`🔧 Draw Text`（类型 `DrawText+`）**。本版使用它绘制真实字体，其他环节使用原生节点。

## 先补中文字体，再导入

你当前的字体下拉只有 `ShareTechMono-Regular.ttf`。将包内 `fonts/NotoSansCJKsc-Regular.otf` 复制到**已安装 Essentials 的 `fonts` 文件夹**，通常是：

```text
ComfyUI/custom_nodes/ComfyUI_essentials/fonts/NotoSansCJKsc-Regular.otf
```

然后刷新 ComfyUI 页面，再导入 `Qwen2.1_宣传图_现有节点版.json`。在节点⑧确认 `font` 能选到 `NotoSansCJKsc-Regular.otf`。如文件夹名字不同，使用 Essentials 实际安装目录；不需要创建或安装新插件。繁体字形风格可同样复制并选择随包的 `NotoSansCJKtc-Regular.otf`。

## 使用

- ①上传素材；②填完整上图原文；③只填无字主视觉的设计要求。
- ④ `amount` 填 1、2、3 或 4，工具栏 Batch Count 保持 1，一次采样批量出图。
- ⑧ `size` 调整字号，默认64；`offset_x=48`、`offset_y=40`、`direction=ltr`。已保留你的原文「咖啡还是我的好」。
- 当前最终尺寸1088×1440：上方主视觉1088×1024，下方文字区1088×416。如改尺寸，需同时调整主视觉空画布、文字空画布、扩展的bottom高度和最终合成y位置。
- 输出前缀 `Qwen_Promo_ExistingFont`。

流程为：Qwen生成无字主视觉 → 原生扩展画布 → 原生合成真实字体文字底板 → 保存。文案只进入 DrawText+，不发给 Qwen；排字后不再经过模型。

⑧的 `img_composite` **只连接单张空白文字底板**，不要改接Qwen解码批次。这样⑧仅绘制一次文字底板，再由⑨的原生合成广播到全部1–4张，避免现成画字节点只处理批次第一张的问题。

**限制：**这个现成节点没有自动缺字检查、自动换行或溢出拦截。长文要由调用方插入真实换行，并检查字号和文字区容量；空文案请先补充。换字体时需确认覆盖所有字符。此版本不能声称保留上一版自定义节点的全部严格校验。Qwen主视觉也仍需看图检查偶发伪文字、主体及品牌效果。

接口版为 `Qwen2.1_宣传图_现有节点_API.json`。原文填 `20.inputs.value`；数量填 `6.inputs.amount`；整个图只提交一次 `/prompt`。

字体来自 [Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk)，许可证和来源信息在fonts内。节点实现依据：[Essentials画字](https://github.com/cubiq/ComfyUI_essentials/blob/main/text.py)、[原生批量合成](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_mask.py)。已核对节点存在、字体选项、连线和当前7字的排版尺寸；尚未在你的GPU上跑新版。
